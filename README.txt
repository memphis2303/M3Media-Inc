LIGHTCRAFT V9
Editorial Studio · Lighting Storyboard and Virtual Studio

START HERE
Unzip the folder and open index.html in a modern browser. The V9 studio,
gear, storyboard, reference images and coach run locally. There is no
installation, login or connection required for V9.

WORKFLOW
1. LightCraft opens on the Storyboard. The first-run Bodyscape guide
   compares the one-light and two-light recipes from the supplied V8
   concept. Apply either recipe, then open the active setup in Studio.
   Use Genre and Lighting technique to explore other comparisons.
   Every setup card shows an overhead diagram, a labeled photo, and
   starting aperture, shutter speed, ISO and strobe power when used.
   Photo captions identify references for a different technique.
2. In Studio view, drag equipment markers to move them across the floor,
   or enter coordinates in Scene controls. Drag the floor to orbit.
   Use Lights in scene to add or remove the key, fill or rim fixture.
   The default Headshot setup starts with just the key light.
   Set the number of lights, reflectors, modifiers, gels or grids in
   Scene controls. You can use up to eight of each. Adjust individual
   fixtures under Adjust an object. Live portrait shows a realistic
   human subject under an approximation of your lighting. Photo
   example shows a fixed reference.
3. Explore all eleven genres in Storyboard, with illustrated pose or
   composition studies, exposure starting points, subject variations and access considerations.
   In the new genre galleries, select an image for an uncropped view.
   Use the arrow buttons or arrow keys to browse the gallery.
4. In Setup Coach, choose mood, room size, subject coverage and gear
   quantities. Choose a mixed or specific modifier, gel and reflector
   palette, then apply the plan. Group plans are aimed at a center
   target in the studio.
   In Gear, choose a light, enter your actual rated output and fit
   modifiers, grids or gels. Adjust reflectors and flags in the scene.
5. Save complete setups in Presets. Export JSON to back up a setup or
   transfer it. V8 workspace exports can also be imported. They carry
   the V8 fine controls and coach preferences.

Changing genre or technique loads the corresponding lighting starting
point. Keep a preset before changing techniques if you want to return
to the current placements.
Use the scene controls and orbit buttons for keyboard operation.

SHOOT CARDS, SHOOT RECORDS AND STUDIO PROFILES
Under Presets, open Lighting card beside a saved setup. Print the
one-page card or choose Save as PDF in the browser print dialog.
The numbered overhead plan matches the equipment and placement table.

Open As shot to record camera settings, on-set notes and an optional
test frame. Use Copy active scene if you changed the rig in the studio.
The original planned setup is kept alongside the shoot record. Lighting
card can show either version. Use Export shoot record to back up both
versions and the test frame, then import that JSON from Presets.

Add a Studio profile with clear room width, depth, ceiling height and
available gear counts. Choose Adapt beside a saved setup and select
the profile. Review the proposed placements and equipment changes in
the 3D studio. Saving creates a separate preset.
The planner uses a rectangular room, generic equipment clearances,
and flash power estimates. Verify fit, safe clearances, and exposure
with the equipment and room on site.

HOW THE PREVIEWS WORK
The live views use sculpted standing and seated figures with selectable
skin tones, proportions and orientation. They approximate distance falloff,
light direction, color, soft light, bounce and shadows. The subject
models and lighting are simplified. Use a meter or test exposure on set.

Live portrait uses two AI-generated subject images and a 2D lighting
simulation. It responds to the active fixtures, power, placement,
softness, modifiers, gels, reflector and flag. The portrait pose and
framing are fixed. Studio shows placement and subject rotation.
Tabletop scenes use the Studio view.

The bundled AI-generated photo examples illustrate specific lighting
techniques. Captions identify their genre and technique. When a matching
genre example is unavailable, the app shows a labeled example of the
technique from another genre. Photos stay fixed as you edit the scene.
There is no on-demand image generation service in this package.

ORIGINAL V8
Open Original V8 Tools at the bottom of the app to use the original
reference library and tools. The legacy 3D viewer still uses its original
external Three.js dependency. Browser storage is tied to the browser and
the location of the app. Export JSON before moving the folder.

V9.1 CHANGES · IMAGE POLICY AND SHOOT GUIDES
Every genre and lighting technique now uses the same guide layout as the
Bodyscape page: two setup cards (overhead diagram, image reference,
technique note, aperture, shutter, ISO, strobe power) followed by pose
studies with their own lighting recipe.

Image policy: models are adults aged 20-50. Fitness is shot in the photo
studio. Only the Outdoor genre uses outdoor locations.

Image repairs: Portrait and Fashion include replacement photographs for
the standing pocket pose and structured coat pose. Boudoir uses the
six supplied photographs and the existing loungewear references for
the under-the-sheets and brown-backdrop studies. All study images are
bundled and load directly from the extracted folder.

To update a study, replace the corresponding JPG in the assets folder
using the existing filename.
